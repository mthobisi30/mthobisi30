## Featured Projects

### MPIA Services — Industrial NDT Inspection Platform
**Stack:** Next.js 15 · TypeScript · Flutter · Tauri 2 (Rust) · PostgreSQL · Prisma · NextAuth v5

A seven-surface operations platform for a non-destructive testing company — admin web/desktop, client portal (web/desktop/mobile), field mobile, and marketing site — all driven by one central PostgreSQL database. Offline-first field capture syncs from local SQLite on reconnection, with Ed25519-signed Tauri desktop installers and auto-updates. Tenant-scoped client access, granular permissions, and audit logging across jobs, reports, invoices, and inspection records.

---

### ElevateTech — Manufacturing PIM, Supplier Portal & Commerce — [Live Store](https://store.elevatetech.biz)
**Stack:** Next.js · React · React Native · TypeScript · PostgreSQL · Prisma · Docker · Coolify

Four connected surfaces — a Product Information Management system, a supplier portal, a customer store, and a React Native mobile app — running over one shared product database. Features bulk CSV import/export, change-history audit trails, role-based dashboards, and automated inventory sync via cron jobs. Containerised on self-hosted Coolify with zero-downtime releases and automated migrations.

---

### RedHailer — Service & Product Marketplace *(Contract for Qwezy Digitals)*
**Stack:** Next.js · TypeScript · PostgreSQL · Prisma · NextAuth · PayStack · Pusher · Capacitor

A full-stack marketplace with client/provider role switching, service listings, and a product catalogue with inventory tracking. Integrates PayStack payments with server-side verification, Pusher real-time chat, and QR-code job acceptance/completion workflows. Shipped natively to Android/iOS via Capacitor with OpenStreetMap geocoding and distance-based delivery pricing.
